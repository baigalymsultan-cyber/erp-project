# TEST GAPS — Missing Regression Scenarios (2026-10-04)

Read-only hunt over `tests/` (48 files). Each gap below is a REAL scenario the
suite does not cover, where a regression would go unnoticed. For every gap the
closest existing test is cited (file:line) — or NONE when nothing is near.

Severity key: **P1** = financial misstatement / data corruption risk,
**P2** = API contract / security / correctness gap.
