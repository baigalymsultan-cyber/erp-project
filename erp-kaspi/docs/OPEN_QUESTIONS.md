# OPEN QUESTIONS (§95)

Ответы **не выдумываются**. До получения ответа реализация использует
конфигурируемые/историзируемые структуры, а не зашитые константы.

| ID | Вопрос | Область | Блокирует | Временное решение |
|---|---|---|---|---|
| OQ-001 | Налоговый режим каждого ИП (упрощёнка/розничный/общеустановленный), ставки, ОПВ/СО/ВОСМС за сотрудников | Налоги (§75) | Расчёт net profit после налогов, payroll-удержания | Таблица `tax_rates_history` (ARCHITECTURAL EXTENSION), ставки не зашиты. Расчёт налогов не реализуется до ответа |
| OQ-002 | Точная структура Excel-файлов: названия листов, колонок, формат дат, формат сумм, наличие заголовков | ETL (§39) | ШАГ 2 | Конфигурируемый маппинг колонок в YAML/JSON |
| OQ-003 | Официальная спецификация Kaspi Shop API и Kaspi Pay API: endpoints, auth, поля ответов, пагинация, rate limits | Интеграция (§42, §94) | ШАГ 3, ШАГ 4 | `BLOCKED — EXTERNAL API SPECIFICATION REQUIRED`. Клиенты пишутся с абстрактным транспортом; поля payload не выдумываются, хранится raw JSONB |
| OQ-004 | Правила Kaspi payout: периодичность, состав реестра, как отражаются комиссия/доставка/возвраты, частичные выплаты | Финансы (§44) | Reconciliation | Модель payout/payout_items хранит суммы «как пришли»; правила сверки — параметризуемые допуски |
| OQ-005 | Размер и структура комиссии Kaspi (по категориям? по способу оплаты? рассрочка/кредит отдельно?) | Финансы | Себестоимость заказа, маржа | Комиссия хранится по факту в `orders.kaspi_commission`, не рассчитывается |
| OQ-006 | Правила возвратов: полный/частичный, влияние на payout, срок, кто платит доставку | Финансы | Refund-логика | Reversal-модель через `related_operation_id` |
| OQ-007 | Правила зарплаты: размер оклада по сотрудникам, состав бонусов, виды удержаний, период (месяц/2 недели), аванс | Payroll (§34–36) | ШАГ 7 | Поля `base_salary`/`bonuses`/`deductions` вводятся вручную; формула суммирования нейтральна |
| OQ-008 | Производственные нормативы: нормы времени, допустимые отклонения, брак/переделка — кто платит | Производство | Контроль work_entries | Валидация только на положительность количества |
| OQ-009 | Банковские счета: сколько, в каких банках, нужна ли выгрузка/интеграция, формат выписки | Финансы (§51) | Банковский модуль | Generic `accounts` и явные source/destination accounts для cross-IP transfer определены; банковские реквизиты, выписки и интеграция остаются DEFERRED |
| OQ-010 | Распределение общих расходов (аренда, коммунальные, реклама) между ИП и между заказами | Финансы | Полная себестоимость | Реализуется только Direct Cost (§37). Аллокация накладных — DEFERRED |
| OQ-011 | Права пользователей: точный перечень действий для BRIGADIER, SHOP_MANAGER, HR — что именно можно менять/видеть | RBAC (§53) | ШАГ 8 | Базовая матрица по §53, уточняется |

| OQ-013 | Сколько ИП и их реквизиты (наименование, БИН) | Данные | Seed | Seed данных ИП не создаётся, только справочники (§85) |
